## StoryOS Example Workflow
StoryOS is a flexible tool that has many available workflows.
An example workflow is provided that includes importing the example story, which will create:
1) Project
2) World
3) Characters
4) Locations
5) Props
6) Scenes
7) Shots
8) Storyboard frames
9) Editorial assets
10) Sequence

AI assistants will then provide assistance by
analyzing the example story and aligning it with a story graph
making some changes, including suggesting visual style using production terminology

Finally, you will begin generating some visual assets, which will then be imported into StoryOS when rendered by ComfyUI and a final sequence can be rendered for the entire story.

The additional chapters of the document will detail more advanced workflows, including:
Exporting the example story as a script
Sequencing assets in StoryOS and exporting an EDL

Very advanced functionality is coming, including:
Building a character LORA for character consistency
Importing scripts into StoryOS
Importing EDLs into StoryOS
