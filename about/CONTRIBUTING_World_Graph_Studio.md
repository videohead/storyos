# Contributing to World Graph Studio

Thank you for your interest in contributing to World Graph Studio.

World Graph Studio is an open-source creative production studio that keeps structured story data and filmmaking tools in WordPress, with optional connections to generation and publishing services.

## Our Mission

Build an open, extensible platform that enables creators to manage the complete storytelling lifecycle from concept through production and editorial delivery.

## Getting Started

1. Fork the repository.
2. Create a feature branch.
3. Make focused changes.
4. Document your work.
5. Submit a pull request.

## Branch Naming

Recommended format:

```text
feature/short-description
bugfix/short-description
docs/short-description
```

Examples:

```text
feature/story-graph-search
bugfix/comfy-workflow-timeout
docs/architecture-update
```

## Pull Request Guidelines

Pull requests should:

- Solve a clearly defined problem.
- Include documentation updates when appropriate.
- Avoid unrelated changes.
- Follow existing project conventions.

Please include:

- Summary
- Motivation
- Implementation details
- Screenshots (if applicable)
- Related issues

## Development Principles

### Story First

Story structure and continuity are more important than individual generated assets.

### Open Standards

Prefer open formats and interoperable systems.

### Creator Ownership

Creators should retain ownership of stories, assets, prompts, and workflows.

### Model Agnostic

Avoid hard dependencies on specific AI vendors or models.

### Story Graph Driven

The Story Graph is the source of truth.

Scripts, storyboards, assets, production plans, and editorial artifacts should derive from structured story data whenever possible.

## Areas of Focus

The current release scope is complete. Useful contribution areas include:

- Story Graph architecture
- WordPress content model design
- Enhancements to WordPress plugins
- Comfy Cloud MCP workflows and local Comfy MCP creator workflows
- WordPress Abilities and Story Graph agent context
- Maintenance of delivered World Graph Studio JSON import and Markdown export
- Production adapters built on the implemented EDL PHP format functions
- Production planning workflows
- Documentation
