# Bundled brand fonts

- `Oswald-VariableFont_wght.ttf` comes from the official Google Fonts Oswald family and is distributed under `OSWALD-OFL.txt`.
- `Inter-VariableFont_slnt,wght.ttf` comes from the WordPress Twenty Twenty-Three theme bundled in this repository and is distributed under `INTER-OFL.txt`.

Both fonts are loaded locally through `theme.json`; the theme does not depend on a third-party font request at runtime.
